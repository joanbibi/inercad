Code signing policy

Política de firma de código

Los ejecutables de InerCAD para Windows se firman digitalmente. La firma te permite comprobar quién publica el archivo y que nadie lo ha modificado después de construirlo.

Free code signing provided by SignPath.io, certificate by SignPath Foundation
Firma de código gratuita proporcionada por SignPath.io, con certificado de SignPath Foundation.

Estado

Los archivos de la versión {{VERSION}} están firmados. En Windows, el firmante que aparece es SignPath Foundation.

Hemos solicitado la firma a SignPath Foundation. Los archivos de la versión {{VERSION}} todavía no están firmados. Mientras tanto, puedes comprobarlos con su huella SHA-256 (ver Comprobar un archivo).

Qué se firma

  • El instalador, {{SETUP_NAME}}.
  • La versión portátil, {{PORTABLE_NAME}}.
  • El ejecutable de la aplicación, InerCAD.exe, que va dentro de los dos anteriores.

Solo se firman binarios construidos a partir del código de este proyecto. Las bibliotecas de Electron y Chromium (archivos .dll) se incluyen sin cambios, tal como las publican sus autores. El desinstalador que genera el empaquetador NSIS no lleva firma propia.

Cómo se construye y se firma

  1. Cada versión parte de una etiqueta vX.Y.Z del repositorio público.
  2. GitHub Actions compila en servidores de GitHub, con el código y los scripts de compilación del repositorio (flujo release.yml). Ningún ejecutable que se publica se compila en un equipo personal.
  3. Los ejecutables se envían a SignPath, que verifica que proceden de esa compilación. Un aprobador del equipo revisa y aprueba a mano cada solicitud de firma.
  4. Los archivos firmados se publican en GitHub Releases junto con SHA256SUMS.txt, y esta web muestra sus huellas.

Privacidad

Este programa no transfiere ninguna información a otros sistemas en red, salvo que lo pida expresamente el usuario o la persona que lo instala o lo utiliza.
  • InerCAD no tiene telemetría, estadísticas de uso, cuentas ni búsqueda automática de actualizaciones.
  • Tus proyectos se guardan solo en tu equipo: en los archivos .inercad que tú guardes y en el autoguardado local de la aplicación.
  • Si pulsas un enlace externo, por ejemplo a esta web, se abre en tu navegador. La aplicación no hace ninguna otra conexión y no muestra anuncios.
  • El instalador funciona sin permisos de administrador. Instala la aplicación para tu usuario, crea los accesos directos y asocia los archivos .inercad; antes de empezar te deja elegir la carpeta de instalación.

Comprobar un archivo

La firma

En el Explorador de archivos, haz clic con el botón derecho en el archivo y abre Propiedades → Firmas digitales: el firmante debe ser SignPath Foundation. También puedes comprobarlo en PowerShell; el estado debe ser Valid:

Get-AuthenticodeSignature .\{{SETUP_NAME}} | Format-List Status, SignerCertificate

La huella SHA-256

Compárala con la que aparece en la página de descargas y en SHA256SUMS.txt:

Get-FileHash .\{{SETUP_NAME}} -Algorithm SHA256

Aunque el archivo esté firmado, Windows SmartScreen puede avisar al ejecutar una versión recién publicada, hasta que acumula reputación con las descargas. Si la firma y la huella coinciden, pulsa Más información y después Ejecutar de todas formas.

Desinstalar

  • Instalador: Configuración → Aplicaciones → Aplicaciones instaladas → InerCAD → Desinstalar. Se quitan la aplicación, los accesos directos y la asociación de archivos .inercad. Tus proyectos guardados no se tocan.
  • Versión portátil: basta con borrar el archivo.
  • ¿Crees que un archivo firmado no procede de este proyecto? Abre una incidencia.
